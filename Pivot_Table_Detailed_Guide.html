Excel Pivot Table – Step-by-Step Guide
Subscribe to our YouTube channel to view the detailed Pivot Table guide.
📚 What you will learn:
Create a Pivot Table, add fields to Rows and Values, change the Report Layout, show Tabular Form, repeat item labels, apply a filter, and move a field to Columns.
1

Step 1 – Start with Your Data

Select the Excel data range you want to summarize. Make sure the data has clear column headers and is arranged in rows.

2

Step 2 – Insert PivotTable

Go to Insert → PivotTable and click OK to create the PivotTable.

3

Step 3 – Add Fields to Rows

Add fields such as Name, Type and Other to the Rows area.

4

Step 4 – Add Quantity to Values

Add Quantity to the Values area so Excel summarizes it, such as Sum of Quantity.

5

Step 5 – Open Report Layout

Go to Design → Report Layout to change the PivotTable layout.

6

Step 6 – Show in Tabular Form

Choose Report Layout → Show in Tabular Form.

7

Step 7 – Repeat All Item Labels

Use Report Layout → Repeat All Item Labels to fill repeated row labels.

8

Step 8 – Apply a Filter

Move Name to Filters and select the required value, such as A.

9

Step 9 – Move a Field to Columns

Drag a field such as Other into Columns to display it across the PivotTable.
